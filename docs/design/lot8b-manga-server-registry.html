À l'instant · cloche + temps réel (WebSocket)

Pourquoi c'est plus sûr. Le hostname n'est plus libre : il devient une liste blanche d'origines (scheme://host[:port]) tenue par l'admin. Une soumission ne crée qu'une entrée pending inerte — aucun appel sortant tant qu'elle n'est pas approuvée, et la garde SSRF (résolution DNS + denylist IP privées/loopback/link-local/CGNAT/metadata) + le client http_no_redirect restent en place même pour les serveurs approuvés. La révocation bascule le statut en revoked : les croisements, badges et le profil cessent de se charger (tout est filtré sur status = 'approved'), et chaque utilisateur lié reçoit une notification in-app (réutilise la table notifications + le bus d'évènements temps réel). Migration : tes liens actuels passent en attente — tu les approuves depuis cette page.
