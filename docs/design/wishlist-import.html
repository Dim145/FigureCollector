Côté technique. Les listes orzgk peuvent être publiques (plugin wlfmc) : le serveur récupère le lien partagé /wishlist-2/view/<token>/ (pagination ?pagenum=N suivie) et parse les lignes tr.wlfmc-table-item (lien produit, titre, version, image, prix). Repli optionnel : coller le HTML d'une liste privée (même parseur). Le % vient d'une similarité de nom (trigramme Postgres) + fabricant ; ≥ 90% → association automatique, sinon choix manuel. À la validation, les correspondances rejoignent juste les souhaits (aucune méta-donnée touchée) ; les nouvelles passent par orzgk/detail (page produit publique) → création catalogue (même mapping que la page d'ajout, version pré-sélectionnée) → souhait. Possédées exclues (règle owned≠wishlist). Plafond : 10 par lot.
